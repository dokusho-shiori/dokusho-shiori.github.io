栞アプリ Flutter版 セットアップ手順
2026年4月4日
================================================================

【パッケージ名】 com.yamaguchi.shiori
【Firebase プロジェクト】 shiori-8fd3f

----------------------------------------------------------------
STEP 1: フォルダ配置
----------------------------------------------------------------

このZIPを解凍して、作業フォルダに置く。
例: C:\AndroidAPP\shiori\

----------------------------------------------------------------
STEP 2: パッケージ取得
----------------------------------------------------------------

VS Codeのターミナルで実行：

  flutter pub get

----------------------------------------------------------------
STEP 3: Galaxyで実行
----------------------------------------------------------------

  flutter run -d <デバイスID>

デバイスIDを確認：
  flutter devices

----------------------------------------------------------------
STEP 4: Firebase Firestoreのルール設定
----------------------------------------------------------------

Firebase Console → Firestore → ルール で以下を設定：

  rules_version = '2';
  service cloud.firestore {
    match /databases/{database}/documents {
      match /users/{userId}/{document=**} {
        allow read, write: if request.auth != null
                           && request.auth.uid == userId;
      }
    }
  }

----------------------------------------------------------------
STEP 5: ビルドエラーが出たら
----------------------------------------------------------------

よくあるエラーと対処：

・Gradle関連エラー
  → android/gradle/wrapper/gradle-wrapper.properties の
    distributionUrl のバージョンを確認

・google-services.json が見つからない
  → android/app/ フォルダに入っているか確認

・flutter pub get でエラー
  → flutter clean してから flutter pub get を再実行
