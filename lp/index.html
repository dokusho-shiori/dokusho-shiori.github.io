Features

ちょうどいい、6つの機能。

余分な機能は要らない。
読書に集中できる設計。

📚

ISBN自動登録

番号を入力するだけで書名・著者・表紙を自動取得。手入力の手間ゼロ。

🗂️

読書ステータス管理

「読みたい・読書中・積読・読了」の4段階で本を整理。進捗バーで何%読んだか確認できます。

✏️

カスタマイズできるメモ

ページ番号・重要度タグつきでメモを記録。本の詳細画面でメモの並び替えやテキストのコピーも可能。メモの種類名は自分好みに変更できます。

📖

本棚ビュー

グリッド表示に切り替えると本の表紙が並んで本棚のように眺められます。

☁️

Googleアカウントで同期

サインインするだけでデータを自動同期。機種変更後もすべての記録が引き継げます。

🔍

検索・フィルター

タイトル・著者・タグで検索。ステータス絞り込みと並び替えで見たい本をすぐ見つけられます。

プライバシーポリシー

waraka（以下「開発者」）は、栞（SHIORI）における利用者の個人情報の取り扱いについて、以下のとおり定めます。

収集する情報

本サービスはGoogleアカウントによるログイン機能を使用します。ログイン時に取得する情報はGoogleアカウントのメールアドレスおよび表示名のみです。登録した本の情報・読書メモはFirebase Cloud Firestoreに保存され、ご本人のみがアクセスできます。

情報の利用目的

取得した情報はサービスの機能提供（クラウド同期・アカウント識別）のみに使用し、第三者への提供・販売は行いません。

データの削除

設定画面の「アカウントを削除」からいつでも全データを削除できます。
